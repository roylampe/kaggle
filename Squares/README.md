# Squares

## Running script:
```
python3 squares.py 5 30 --csv packings.csv           # one n
python3 squares.py 1-10 30 --csv packings.csv        # a range, 30 s per n
python3 squares.py 1,3,7-9 30 0,45 --csv out.csv     # a list, with allowed angles
python3 squares.py 11 60 --csv out.csv --append      # add to an existing file
```
